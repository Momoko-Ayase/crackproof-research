# Verification & reference

This section publishes the complete, runnable reference files and test vectors behind [CrackProof for Windows internals](https://app.gitbook.com/s/PuKTEy2soDgSB3qfWACy/), together with anonymized runtime debug logs.

## Verification suite

Two automated checks validate every Windows transform implementation in this repository:

* **`run_tests.py` (31 comparisons):** runs the standalone Python modules in `verification/` against the 25 ground-truth records in `vectors.txt` (generated by `rust_vectors.rs`).
* **`verify_docs.py` (5 languages, 80 Python blocks, 135 comparisons):** extracts and executes all 16 Python code blocks across the nine transform pages in each of the five language editions (`en`, `zh-cn`, `zh-tw`, `ja`, `ko`), running 27 vector comparisons per language.

```bash
python verification/run_tests.py
python verification/verify_docs.py
```

Expected final lines: `all vectors match` and `all Windows doc snippets verified (5 languages, 80 Python blocks, 135 checks)`.
