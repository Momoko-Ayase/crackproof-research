## 빌드별 `%temp%` 디버그 로그 확보

프로세스 시작 시점에 `CreateFileW`에 브레이크포인트를 걸거나 호출을 트레이싱해 `%temp%` 하위에서 조회되는 12자리 16진수 디렉터리 이름을 확인한 뒤, 해당 폴더를 생성하고(폴더 생성 시각이 약 48시간 이내여야 함) 바이너리를 다시 실행합니다. 보호된 모든 EXE와 DLL이 단계별 실행 트레이스(`HHMMSSmmmE-...` / `HHMMSSmmmD-...`)와 마지막 `AAA-BBB-CCC` 종료 요약 코드를 기록합니다([시작 시퀀스와 상태 보고](../runtime/startup-status.md#the-boot-sequence-and-status-codes) 참고).
{% endstep %}

{% step %}
## 상태 코드를 호스트 및 보조 모듈 코드에 매핑

로깅 헬퍼는 `ECX` 레지스터로 32비트 패킹 값을 전달받으며, 하위 16비트에 단계 상태는 `(code << 4) | 1`, `CCC` 원인 코드는 `| 3`, `BBB` 하위 단계는 `| 5` 형식으로 인코딩됩니다. 핵심 부트스트랩 코드(`200`, `560`, `590`, `5A0`, `5E1`, `5E2`, `800`)는 실행 후 소거되기 전까지 호스트 모듈의 로더 섹션 내부에서 확인할 수 있는 반면, `410`/`510`/`520`/`540`, `Cxx`, `Axx` 즉시값은 수동 매핑된 보조 DLL(`HtpecIt.dll`, `dm` 등) 내부에 위치합니다.
{% endstep %}

{% step %}
## 다형성 디코이와 실제 스테이지 코드 분리

* 범용 레지스터를 통째로 저장하는 타이밍 디코이(`in eax, dx` 직후 변위가 0인 `jne $+2` 실행)와 `TF`(`#DB`) SEH 트랩은 건너뛰고, 예약된 컨텍스트 레지스터를 초기화하는 명령어부터 추적합니다.
* 무조건 점프 뒤의 정크 바이트 때문에 정적 디스어셈블리가 어긋나는 구간에서는 디스크 상의 원본 바이너리를 파일 I/O(`CreateFileW` / `MapViewOfFile`) 백엔드로 연결해 해당 단계를 에뮬레이션하거나, 같은 빌드 계열의 보호된 모듈 두 개를 비교해 공유 스테이지 코드와 빌드별 데이터 테이블을 분리합니다.
{% endstep %}

## VAD 기반 페이지 암호화 모듈 덤프

* 복호화된 페이지는 전용(`MEM_PRIVATE`) 메모리에 위치하므로 파일 캐시 기반 추출기 대신 VAD(Virtual Address Descriptor) 기반 추출기를 사용합니다.
* OEP(`280` 단계) 도달 이후 섹션별 페이지 보호 속성 및 복호화 상태를 확인합니다. 일괄 복호화 모듈(`800 -> 830`)은 모든 실행 페이지가 즉시 복호화되어 있는 반면, 페이지 암호화 모듈(`640 -> 840`)은 아직 실행되지 않은 페이지가 접근 예외를 통한 복호화 전까지 `PAGE_NOACCESS` 상태로 남아 있습니다.
* 프로세스 내부 보조 루틴은 `A07` 외부 스레드 정리가 끝난 뒤에 실행하고, 부팅 완료 후 수 초 간격으로 확보한 두 스냅샷을 비교해 새로 접근되어 복호화된 페이지나 활성화된 `scribble` 재마스킹 여부를 판별합니다.
{% endstep %}

## 복원된 PE 이미지의 정적 무결성 검증

복원된 PE 이미지에 대해 다섯 가지 구조적 불변 조건을 검증합니다.

1. 유효한 `MZ` 및 `PE\0\0` 시그니처와 옵셔널 헤더 매직(`0x10B` 또는 `0x20B`)을 갖추고, 섹션 헤더가 파일 범위 내에 들어올 것.
2. 엔트리 포인트가 0이 아닌 네이티브 모듈의 경우 `AddressOfEntryPoint`가 0으로 비워지지 않은 실행 가능 구간으로 매핑되며, CRT 엔트리 스텁의 `call`/`jmp` 타깃이 `.text` 내부를 가리킬 것.
3. 네이티브 모듈의 최대 256개 `IMAGE_IMPORT_DESCRIPTOR` 전반에서 모듈 이름이 출력 가능한 ASCII `.dll` / `.exe` 문자열로 디코딩되고, 이름 기반 `IMAGE_IMPORT_BY_NAME` 문자열도 출력 가능한 ASCII일 것.
4. 관리형 어셈블리(`DD[14]`가 0이 아님)의 경우 `COR20` 헤더의 `cb == 0x48`이며 참조된 메타데이터 루트가 `BSJB`로 시작할 것.
5. 모든 DLL에서 `BaseReloc` 데이터 디렉터리(`DataDirectory[5]`)가 0이 아니고 `DYNAMIC_BASE`(`0x0040`) 플래그가 설정되어 있을 것.
