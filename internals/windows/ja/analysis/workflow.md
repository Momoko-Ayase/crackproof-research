# 解析ワークフロー

{% stepper %}
{% step %}
## ビルドごとの `%temp%` デバッグログを取得する

プロセス起動直後の `CreateFileW` にブレークポイントを置くか API トレースを取り、`%temp%` 配下で探索される 16 進 12 桁のディレクトリ名を確認します。そのフォルダを作成して（作成日時がおおむね 48 時間以内である必要があります）バイナリを再実行すると、保護されたすべての EXE と DLL がステージ単位のトレース（`HHMMSSmmmE-...` / `HHMMSSmmmD-...`）と末尾の `AAA-BBB-CCC` 終了サマリを書き出します（[起動シーケンスとステータス通知](../runtime/startup-status.md#the-boot-sequence-and-status-codes)を参照）。
{% endstep %}

{% step %}
## ステータスコードからホストと補助 DLL の実装箇所を対応付ける

ログ出力ヘルパーは `ECX` に 32 ビットのパック値を受け取り、その下位 16 ビットにはステージステータスが `(code << 4) | 1`、`CCC` 原因コードが `| 3`、`BBB` サブステージが `| 5` として符号化されています。中核ブートストラップのコード（`200`、`560`、`590`、`5A0`、`5E1`、`5E2`、`800`）は実行後の消去処理が行われる前のホストモジュール内ローダーセクションに現れますが、`410`/`510`/`520`/`540`、`Cxx`、`Axx` の即値は手動マップされた補助 DLL（`HtpecIt.dll`、`dm` など）の内部にあります。
{% endstep %}

{% step %}
## ポリモーフィックなデコイと本来のステージ処理を切り分ける

* レジスタ一式を退避するだけの明白なタイミング計測デコイ（`in eax, dx` の直後に変位ゼロの `jne $+2` が続くパターン）や `TF`（`#DB`）SEH トラップは読み飛ばし、ステージコンテキスト用のレジスタを初期化する命令を起点にトレースします。
* 無条件ジャンプ直後のジャンクバイトで静的逆アセンブルの同期が崩れる箇所では、ディスク上の実バイナリをバックエンドにしたファイル I/O（`CreateFileW` / `MapViewOfFile`）付きで該当ステージをエミュレートするか、同じビルド系統の保護モジュール 2 つを比較してビルド固有のデータテーブルと共通ステージコードを分離します。
{% endstep %}

{% step %}
## ページ暗号化されたモジュールを VAD 単位でダンプする

* 復号済みページはプライベートメモリ上に展開されるため、ファイルキャッシュベースではなく VAD（Virtual Address Descriptor）ベースの抽出手法を使用します。
* OEP（`280`）到達後にセクションごとのページ保護属性（復号状態）を確認します。一括復号モジュール（`800 -> 830`）では実行可能ページが最初からすべて展開されていますが、ページ暗号化モジュール（`640 -> 840`）では未実行ページがアクセス違反を経てオンデマンド復号されるまで `PAGE_NOACCESS` のまま残ります。
* プロセス内に補助スレッドを注入して走査する場合は `A07` の外部スレッド強制終了パスの完了後に実行し、起動完了後に数秒間隔で取得した 2 つのスナップショットを比較して、新たにオンデマンド復号されたページや `scribble` による再マスク動作の有無を確認します。
{% endstep %}

{% step %}
## 再構築した PE イメージを静的に検証する

復元した PE を信頼する前に、以下の 5 つの構造的不変条件を検証します。

1. 有効な `MZ` および `PE\0\0` シグネチャ、Optional Header マジック（`0x10B` または `0x20B`）、およびファイル範囲内に収まるセクションヘッダを持つこと。
2. 非ゼロのエントリポイントを持つネイティブモジュールでは、`AddressOfEntryPoint` が非ゼロの実行可能領域内を指しており、CRT エントリスタブ内の `call`/`jmp` 先も `.text` 内に収まっていること。
3. ネイティブモジュールの最大 256 個の `IMAGE_IMPORT_DESCRIPTOR` にわたり、モジュール名が印字可能な ASCII の `.dll` / `.exe` 名にデコードでき、名前解決インポートの `IMAGE_IMPORT_BY_NAME` 文字列も印字可能な ASCII であること。
4. マネージドアセンブリ（`DD[14]` が非ゼロ）では、`COR20` ヘッダの `cb == 0x48` であり、参照先のメタデータルートが `BSJB` で始まること。
5. すべての DLL において、`DataDirectory[5]`（`BaseReloc`）が非ゼロであり、かつ `DYNAMIC_BASE`（`0x0040`）がセットされていること。
{% endstep %}
