# 校驗清單

1. 確認 ELF64、小端 AArch64 以及預期的動態鏈接節。
2. 定位且只接受一個私有 `SHT_LOUSER` 節，並限定其文件範圍。
3. 解碼第一階段，檢查保留字段、對齊、副本長度和映像範圍。
4. 解析第二階段描述符，不得越過父記錄流邊界。
5. 加載 `0x9B`、`0x9D` 和 `0x9E`；缺少或重複定義時拒絕。
6. 每次原始或壓縮寫入都必須精確消耗源數據並達到目標長度。
7. 重建動態鏈接表，校驗數量、版本、哈希和重定位。
8. 從磁盤校驗入口點已清零、`PT_LOAD` 範圍（包括為重建動態表新增的只讀段）成立且節之間的關係可解析。
9. 存在元數據時，檢查魔數、受支持的版本（29、31 或 39，各有自己的表佈局）、表偏移、RID 區間和冪等清理。不要把 Windows `-GMD` 重映射套到 Android 令牌塊上，也不要用版本 31 的步長解碼其他版本。

任一步失敗都表示候選狀態未知，不得報告為部分恢復成功。
