# 常量

以下值來自當前 Android SO 樣本。它們可用於識別構建家族，但不能替代結構檢查。

| 值 | 範圍 |
| --- | --- |
| ELF64、小端、AArch64 | 文件架構 |
| 一個 `SHT_LOUSER` 節 | 私有節識別 |
| `0x23c`（572） | 已觀察的第一階段外層包裝 |
| `0x1000` | 包裝之後的加密參數區；前 32 字節是詞頭 |
| `0xbf20165d`、`0xbf189bdd` | 已觀察的第一階段字常量（每個家族用其中一個） |
| `0x94511dd2` / `0x579357eb` | GF(2³²) 乘數 / 約化多項式 |
| `00 01 0e 00` | AES-256 日程標記（bits `0x0100`，14 輪） |
| `0xE2` | 第二階段初始流標識 |
| `0x5c` | 第二階段記錄和受保護描述符大小 |
| `0x1800` / `0x18` | 第二階段模塊表大小 / 項大小（256 槽） |
| `0xD0` | 第二階段開始時登記的文件尾映射 |
| `0xF3`–`0xF8` / `0xE3`–`0xE8` | 直接數據對象及其子解釋器 |
| `0x9B`、`0x9D`、`0x9E` | 恢復所需模塊 |
| `0x0C` | 僅 IL2CPP 的 `mmap` 掛鉤，用於方法令牌 |
| `0xa6fae968` | 模塊 `0x0C` 中已觀察的默認方法令牌種子 |
| `0x98` | 調用恢復後 `.init_array` 的移交模塊 |
| `0xFAB11BAF`、版本 `29` / `31` / `39` | 識別的 IL2CPP 元數據 |
| `0xFAB11BAF`、版本 `24` | 解包後的內嵌 slim 元數據塊 |
| `lib__XXXX__.so`、`assets/<id>/data1.dat` | 伴生保護庫與旁路配置 |

樣本出現差異時，記錄新值及其來源，並重新運行所有範圍和關係檢查。不要為了適配孤立常量而放寬解析器。
