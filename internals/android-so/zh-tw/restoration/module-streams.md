# 模塊記錄流

初始流標識為 `0xE2`。第二階段先在 256 項表（`0x1800` 字節，每槽 24 字節）裡把自身登記為 `0xE2`，把文件尾映射登記為 `0xD0`。ELF 恢復所需的模塊集合如下：

| 模塊 | 作用 |
| --- | --- |
| `0x9B` | 種子、AES 材料和配置 |
| `0x9D` | 受保護描述符、分段和寫入流 |
| `0x9E` | 隱藏動態符號補丁 |

直接記錄根據命令標識得到子標識。分發器維護模塊註冊表，只把記錄交給聲明瞭該標識的模塊。它記錄每個已接受子流的內容哈希，避免同一記錄流悄悄覆蓋已有範圍。

未知模塊、缺少必需模塊，或子記錄聲明範圍超出父記錄時，恢復停止。部分鏡像不會作為成功結果輸出。
