# 模組串流

Stage 2 串流擷取由根串流 `0xE2` 開始（執行期的 256 格模組表會將根串流本身登記在 `0xE2`，並將 `SHT_LOUSER` 尾端映射區登記在 `0xD0`），接著遞迴解碼所有容器與巢狀直譯器串流（由記錄 `0xF3`..`0xF8` 載入的 `0xE3`..`0xE8`）。

## 靜態還原模組

除了還原程式庫所需的資料模組外，受保護的原生程式庫也包含執行期環境檢查與完整性驗證模組。靜態重建會使用三個必備模組，以及最多三個選用模組：

| 模組 | 必要性 | 靜態還原用途 |
| --- | --- | --- |
| `0x9B` | 必備 | 提供 `header_seed`、`container_seed`、位元組反序的 AES-256 解密金鑰展開表，以及 `skip_aes` |
| `0x9D` | 必備 | 提供 `ProtectedDescriptor`、主要的 `PT_LOAD` 寫入容器，以及包含重定位與符號資料的輔助容器 |
| `0x9E` | 必備 | 提供從磁碟 ELF 檔案中移除的隱藏 `.dynsym` 項目與 `.dynstr` 符號名稱 |
| `0x96` | 選用 | 提供 `auxiliary_symbol_seed`，用於還原 `0x9D` 輔助重定位表中逐列旋轉的符號索引 |
| `0x98` | 選用 | 以步數受限的 AArch64 控制流與整數直譯器模擬執行，還原真實的 `.init_array` 建構函式，並剔除僅含單條 `RET` 的佔位項目 |
| `0x0C` | 選用（IL2CPP `v24.1`） | 提供外部 `v24.1` `global-metadata.dat` 所需的 `methodIndex` 置換種子與 256 項例外表 |

## 重複與非還原用途的記錄

* **僅供執行期使用的模組：** 用於環境探測、匯入輔助常式或未分類識別碼的記錄（`0x8F`、`0x97`、`0x81`、`0x40`、`0x8E`，以及[執行期模組](../runtime/modules.md)所列的其他項目）會在走訪串流時完成解碼與驗證，但在重建 ELF 時略過不用。
* **重複記錄處理：** 若兩筆記錄的 `command_id` 與 SHA-256 雜湊值皆相同，擷取流程只會保留一份；若同一 `command_id` 出現不同的雜湊值，則直接報錯中止。
* **缺少基礎模組：** 串流走訪結束後，只要缺少 `0x9B`、`0x9D` 或 `0x9E` 其中任一模組，ELF 還原就會立即中止，不會輸出檔案。
