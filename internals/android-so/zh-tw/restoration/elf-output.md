# ELF 輸出

最終鏡像依據恢復範圍和原有程序首部關係重建。輸出檢查包括：

* ELF64、小端 AArch64 識別；
* 程序首部表和節首部表範圍位於文件內；
* `PT_LOAD` 對齊、文件大小和內存大小關係；
* 動態節指針指向恢復後的表；
* 重定位項大小和數量；
* 入口點位於可執行的映射範圍內。

通過這些檢查後，移除或中和私有保護節，並把受保護入口替換為恢復後的原生入口。保護專用填充不會因為填補文件空洞就被複制進可加載節段。

輸出還會從磁盤重新解析。內存中的重建成功但二次解析失敗時，仍視為恢復失敗。
