# ELF 輸出

最終映像依據恢復範圍和原有程序頭關係重建。輸出檢查包括：

* ELF64、小端 AArch64 識別；
* 程序頭表和節頭表的範圍落在文件內；
* `PT_LOAD` 對齊、文件大小和內存大小關係；
* 動態節指針指向恢復後的表；
* 重定位項大小和數量；
* 入口點字段清零——殘留的保護層入口意味著恢復失敗。

私有保護節總是最後一個節頭，從輸出中省略。入口點字段被清零而不是替換：不存在恢復出的原生 ELF 入口，原生構造函數經 `.init_array` 運行。

緊湊佈局下程序頭表會多出一個用於重建動態表的只讀 `PT_LOAD`（見[動態鏈接](dynamic-linking.md)）。保護專用填充不會因為填補文件空洞就被複制進可加載段。

輸出還會從磁盤重新解析。內存中的重建成功但二次解析失敗時，仍視為恢復失敗。
