# 動態鏈接

受保護範圍展開後，動態鏈接模塊恢復 Android 加載器所需的信息。

模塊 `0x9D` 提供目標容器和輔助容器，用於生成 `.dynsym`、`.dynstr`、`.gnu.hash`、`.gnu.version`、`.gnu.version_r` 及重定位表。恢復後的偏移和大小必須位於對應 `PT_LOAD` 範圍內，並符合文件對齊規則。

模塊 `0x9E` 應用隱藏符號補丁。只有符號索引、名稱偏移、版本索引和目標地址都指向恢復後的表時，補丁才會接受。GNU 哈希表、版本數組和重定位記錄使用的符號數必須一致；不一致時拒絕，不用啟發式方式修補。

重建的表在原始文件窗口（`.dynsym` 之後）足夠大時就放回原處。緊湊映像的窗口太小，恢復後的表改放在現有加載映像之後新增的只讀 `PT_LOAD` 中，按原 `PT_LOAD` 對齊，動態標記隨之更新到新地址。相鄰節絕不被覆蓋，也絕不發出不完整的表集合。
