# 運行時

靜態恢復從私有節重建 ELF 鏡像。本組說明同一批記錄在庫加載時做什麼：第一階段如何定位自身，第二階段如何解釋嵌套流，以及物化後的模塊檢查或恢復什麼。

恢復仍然只需要模塊 `0x9B`、`0x9D` 和 `0x9E`。其餘標識是運行時對象。恢復後的鏡像裡沒有它們，並不表示恢復失敗。
