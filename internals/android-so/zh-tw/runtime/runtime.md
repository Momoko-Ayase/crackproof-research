# 運行時

靜態恢復從私有節重建 ELF 映像。加載時，第一階段定位自身，第二階段解釋嵌套流，落地後的模塊再檢查或恢復該映像。

恢復仍然只需要模塊 `0x9B`、`0x9D` 和 `0x9E`。其餘標識是運行時對象。恢復後的映像裡沒有它們，並不表示恢復失敗。
