# 模塊配置

配置記錄由模塊 `0x9B` 提供，包含容器模塊和符號模塊需要的種子及 AES 材料。

| 值 | 用途 |
| --- | --- |
| 首部種子 | 解碼外層容器首部時使用的後備種子 |
| 容器種子 | 容器滾動變換的種子 |
| AES-256 密鑰或展開調度表 | 可選的分組密碼層 |
| AES 跳過標誌 | 表示此構建沒有 AES 層 |

調度表靠唯一的四字節標記 `00 01 0e 00` 識別（小端 bits `0x0100`，輪數 14）。隨後 15 × 16 字節是展開的 AES-256 解密輪密鑰，每個詞按字節反序存放。

32 字節密碼密鑰從最後兩輪輪密鑰恢復：末輪密鑰再拼上上一輪的 MixColumns。同一標記出現第二次、調度表被截斷，或輪數不是 14，都是格式錯誤。

跳過標誌在解釋器側 `0x9B` 映像裡位於標記之後的固定距離。裝在第二階段映像裡的嵌入式解碼器在該標誌之前結束，因此對該佈局它定義上為假。

嵌入式解碼器在沒有容器種子時使用首部種子作為後備。這是已觀察到的佈局，不意味著可以從明文猜測種子。
