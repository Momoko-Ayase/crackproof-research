# 运行时

静态恢复从私有节重建 ELF 镜像。本组说明同一批记录在库加载时做什么：第一阶段如何定位自身，第二阶段如何解释嵌套流，以及物化后的模块检查或恢复什么。

恢复仍然只需要模块 `0x9B`、`0x9D` 和 `0x9E`。其余标识是运行时对象。恢复后的镜像里没有它们，并不表示恢复失败。
