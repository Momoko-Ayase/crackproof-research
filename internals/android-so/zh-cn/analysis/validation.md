# 校验清单

1. 确认 ELF64、小端 AArch64 以及预期的动态链接节。
2. 定位且只接受一个私有 `SHT_LOUSER` 节，并限定其文件范围。
3. 解码第一阶段，检查保留字段、对齐、副本长度和镜像范围。
4. 解析第二阶段描述符，不得越过父记录流边界。
5. 加载 `0x9B`、`0x9D` 和 `0x9E`；缺少或重复定义时拒绝。
6. 每次原始或压缩写入都必须精确消耗源数据并达到目标长度。
7. 重建动态链接表，校验数量、版本、哈希和重定位。
8. 从磁盘校验入口点已清零、`PT_LOAD` 范围（包括为重建动态表新增的只读段）成立且节之间的关系可解析。
9. 存在元数据时，检查魔数、受支持的版本（29、31 或 39，各有自己的表布局）、表偏移、RID 区间和幂等清理。不要把 Windows `-GMD` 重映射套到 Android 令牌块上，也不要用版本 31 的步长解码其他版本。

任一步失败都表示候选状态未知，不得报告为部分恢复成功。
