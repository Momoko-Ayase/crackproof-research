# 常量

以下值来自当前 Android SO 样本。它们可用于识别构建家族，但不能替代结构检查。

| 值 | 范围 |
| --- | --- |
| ELF64、小端、AArch64 | 文件架构 |
| 一个 `SHT_LOUSER` 节 | 私有节识别 |
| `0x23c`（572） | 已观察的第一阶段外层大小 |
| `0xbf20165d`、`0xbf189bdd` | 已观察的第一阶段字常量（每个家族用其中一个） |
| `0xE2` | 第二阶段初始流标识 |
| `0x5c` | 第二阶段记录和受保护描述符大小 |
| `0x1800` / `0x18` | 第二阶段模块表大小 / 项大小（256 槽） |
| `0xD0` | 第二阶段开始时登记的文件尾映射 |
| `0xF3`–`0xF8` / `0xE3`–`0xE8` | 直接数据对象及其子解释器 |
| `0x9B`、`0x9D`、`0x9E` | 恢复所需模块 |
| `0x0C` | 仅 IL2CPP 的 `mmap` 挂钩，用于方法令牌 |
| `0x98` | 调用恢复后 `.init_array` 的移交模块 |
| `0xFAB11BAF`、版本 `31` | 识别的 IL2CPP 元数据 |

样本出现差异时，记录新值及其来源，并重新运行所有范围和关系检查。不要为了适配孤立常量而放宽解析器。
