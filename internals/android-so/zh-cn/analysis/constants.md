# 常量

下表列出已分析的 CrackProof Android AArch64 构建中观测到的格式常量。结构边界与跨表一致性校验优先于任何单一常量。

## ELF 与第一阶段

| 常量 | 作用范围 |
| --- | --- |
| ELF64、小端序、`EM_AARCH64`（`183` / `0xB7`） | 必需的文件类别、字节序与架构（`e_phentsize = 0x38`，`e_shentsize = 0x40`） |
| `SHT_LOUSER`（`0x80000000`） | 位于 `PT_LOAD` 文件末尾 16 字节对齐处的单个尾部载荷私有节 |
| `0x84` 字节（`15 × STP` .. `15 × LDP; RET`） | 由 `.init_array` 引用的第一阶段引导寄存器保存包装函数 |
| `0x23C`（572） | 已观测到的第一阶段外层包装大小（`outer_size`） |
| `0x1000` / `0x20` | 第一阶段参数区大小 / 第一阶段 8 双字头部大小 |
| `0xBF20165D`、`0xBF189BDD` | 已观测到的第一阶段字密码常量 `C`（每个构建族对应一个） |
| `lib__XXXX__.so`、`assets/<id>/data1.dat` | 配套保护壳桩共享库与按库划分的配置数据块 |

## 密码算法、容器与第二阶段数据流

| 常量 | 作用范围 |
| --- | --- |
| `0x94511DD2` / `0x579357EB` | `gf32_mul_fixed` 中的 GF(2³²) 固定乘数 / 约化多项式 |
| `00 01 0e 00` | `Module9bConfig` 轮密钥编排标记（标志 `0x0100`、14 轮 AES-256、`0xF0` 字节轮密钥） |
| `0xE2` | 第二阶段根解释器数据流 ID |
| `0xE3`..`0xE8` / `0xF3`..`0xF8` | 嵌套解释器模块及其输入流直接切片（`sid = command_id - 0x10`） |
| `0xD0` | 第二阶段入口处注册的 `SHT_LOUSER` 文件尾部映射槽位 |
| `0x1800` / `0x18` | 第二阶段运行时模块表总大小 / 槽位步长（共 256 个槽位） |
| `0x5C`（23 个双字） | 第二阶段记录描述符与 `0x9D` `ProtectedDescriptor` 的字节大小 |
| `0x2` / `0x100` | 描述符 `DIRECT_FLAG`（直接切片） / 跳过 `init` 与 `entry` 回调的标志 |
| `0x1B00` | 容器头 `ContainerHeader` 中 Huffman 表的最大字节大小（`tree_size`） |

## 静态还原与 IL2CPP 元数据

| 常量 | 作用范围 |
| --- | --- |
| `0x9B`、`0x9D`、`0x9E` | 必需的 ELF 还原基础模块（配置、主容器与辅助 ELF 容器、隐藏符号） |
| `0x96`、`0x98`、`0x0C` | 可选静态还原模块（辅助符号种子、`.init_array` 构造函数解释器、`v24.1` 元数据种子与例外表） |
| `0x403`、`0x101`、`0x401`、`0x402` | 辅助 AArch64 重定位类型：`RELATIVE`、`ABS64`、`GLOB_DAT`（`relocation1`）与 `JUMP_SLOT`（`relocation2`） |
| `0xD65F03C0`（`RET`） | 执行 `0x98` 构造函数恢复时剔除的 `.init_array` 占位目标 |
| `0xFAB11BAF`，版本 `24`（`v24.1`）、`29`、`31`、`39` | 已观测到的外部 IL2CPP 元数据魔数与版本布局 |
| `0xA6FAE968` | 模块 `0x0C` 中观测到的默认 `MethodDef` 置换种子 |
| `0x2701F30`、`[0x9732CA38, 0xBAC4374F]` | 内嵌 XOR 封装精简版 v24 元数据大小及解封后的字节序反转头部探测双字 |
