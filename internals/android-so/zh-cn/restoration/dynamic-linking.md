# 动态链接

受保护范围展开后，动态链接模块恢复 Android 加载器所需的信息。

模块 `0x9D` 提供目标容器和辅助容器，用于生成 `.dynsym`、`.dynstr`、`.gnu.hash`、`.gnu.version`、`.gnu.version_r` 及重定位表。恢复后的偏移和大小必须位于对应 `PT_LOAD` 范围内，并符合文件对齐规则。

模块 `0x9E` 应用隐藏符号补丁。只有符号索引、名称偏移、版本索引和目标地址都指向恢复后的表时，补丁才会接受。GNU 哈希表、版本数组和重定位记录使用的符号数必须一致；不一致时拒绝，不用启发式方式修补。

重建的表在原始文件窗口（`.dynsym` 之后）足够大时就放回原处。紧凑镜像的窗口太小，恢复后的表改放在现有加载镜像之后新增的只读 `PT_LOAD` 中，按原 `PT_LOAD` 对齐，动态标记随之更新到新地址。相邻节绝不被覆盖，也绝不发出不完整的表集合。
