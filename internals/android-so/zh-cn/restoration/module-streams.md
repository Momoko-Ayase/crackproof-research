# 模块记录流

初始流标识为 `0xE2`。ELF 恢复所需的模块集合如下：

| 模块 | 作用 |
| --- | --- |
| `0x9B` | 种子、AES 材料和配置 |
| `0x9D` | 受保护描述符、分段和写入流 |
| `0x9E` | 隐藏动态符号补丁 |

直接记录根据命令标识得到子标识。分发器维护模块注册表，只把记录交给声明了该标识的模块。它记录每个已接受子流的内容哈希，避免同一记录流悄悄覆盖已有范围。

未知模块、缺少必需模块，或子记录声明范围超出父记录时，恢复停止。部分镜像不会作为成功结果输出。
