# 模块配置

配置记录由模块 `0x9B` 提供，包含容器模块和符号模块需要的种子及 AES 材料。

| 值 | 用途 |
| --- | --- |
| 首部种子 | 解码外层容器首部时使用的后备种子 |
| 容器种子 | 容器滚动变换的种子 |
| AES-256 密钥或展开密钥表 | 可选的分组密码层 |
| AES 跳过标志 | 表示此构建没有 AES 层 |

展开后的 AES 密钥表要么不存在，要么具有 AES-256 所需的大小。密钥表损坏、密钥大小不支持，或跳过标志与记录长度矛盾时，模块失败。

嵌入式解码器在没有容器种子时使用首部种子作为后备。这是已观察到的布局，不意味着可以从明文猜测种子。
