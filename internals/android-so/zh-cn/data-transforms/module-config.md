# 模块配置

配置记录由模块 `0x9B` 提供，包含容器模块和符号模块需要的种子及 AES 材料。

| 值 | 用途 |
| --- | --- |
| 首部种子 | 解码外层容器首部时使用的后备种子 |
| 容器种子 | 容器滚动变换的种子 |
| AES-256 密钥或展开密钥表 | 可选的分组密码层 |
| AES 跳过标志 | 表示此构建没有 AES 层 |

日程靠唯一的四字节标记 `00 01 0e 00` 识别（小端 bits `0x0100`，轮数 14）。随后 15 × 16 字节是展开的 AES-256 解密轮密钥，每个词按字节反序存放。32 字节密码密钥从最后两轮轮密钥恢复：末轮密钥再拼上上一轮的 MixColumns。同一标记出现第二次、日程被截断，或轮数不是 14，都是格式错误。

跳过标志在解释器侧 `0x9B` 映像里位于标记之后的固定距离。装在第二阶段映像里的嵌入式解码器在该标志之前结束，因此对该布局它定义上为假。嵌入式解码器在没有容器种子时使用首部种子作为后备。这是已观察到的布局，不意味着可以从明文猜测种子。
