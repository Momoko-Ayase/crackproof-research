# 定数一覧

以下の表は、解析済みの CrackProof Android AArch64 ビルドで確認されたフォーマット定数の一覧です。実際の判定では個々の定数値よりも構造上の境界条件やテーブル間の整合性チェックが優先されます。

## ELF と Stage 1

| 定数 | 対象・用途 |
| --- | --- |
| ELF64、リトルエンディアン、`EM_AARCH64`（`183` / `0xB7`） | 必須のファイルクラス、エンディアン、アーキテクチャ（`e_phentsize = 0x38`、`e_shentsize = 0x40`） |
| `SHT_LOUSER`（`0x80000000`） | 16 バイト境界に切り上げた `PT_LOAD` ファイル終端に置かれる末尾の単一専用セクション |
| `0x84` バイト（`15 × STP` .. `15 × LDP; RET`） | `.init_array` から参照される Stage 1 ブートストラップのレジスタ退避ラッパー |
| `0x23C`（572） | 確認された Stage 1 外側ラッパーのサイズ（`outer_size`） |
| `0x1000` / `0x20` | Stage 1 パラメーター領域サイズ / 8 dword の Stage 1 ワードヘッダーサイズ |
| `0xBF20165D`、`0xBF189BDD` | 確認された Stage 1 ワード暗号定数 `C`（ビルド系統ごとに 1 つ） |
| `lib__XXXX__.so`、`assets/<id>/data1.dat` | 同梱されるプロテクタースタブ共有ライブラリとライブラリ別の設定ブロブ |

## 暗号・コンテナー・Stage 2 ストリーム

| 定数 | 対象・用途 |
| --- | --- |
| `0x94511DD2` / `0x579357EB` | `gf32_mul_fixed` で用いられる GF(2³²) の固定乗数 / 既約多項式 |
| `00 01 0e 00` | `Module9bConfig` の鍵スケジュールマーカー（フラグ `0x0100`、AES-256 の 14 ラウンド、ラウンド鍵 `0xF0` バイト） |
| `0xE2` | Stage 2 ルートインタープリターのストリーム ID |
| `0xE3`..`0xE8` / `0xF3`..`0xF8` | 多段インタープリターモジュールと、それぞれに渡される直接入力ストリームスライス（`sid = command_id - 0x10`） |
| `0xD0` | Stage 2 開始時に登録される `SHT_LOUSER` ファイル末尾マッピングのスロット |
| `0x1800` / `0x18` | Stage 2 ランタイムモジュールテーブルの全体サイズ / スロット幅（256 スロット） |
| `0x5C`（23 dword） | Stage 2 レコード記述子および `0x9D` 内 `ProtectedDescriptor` のバイトサイズ |
| `0x2` / `0x100` | 記述子の `DIRECT_FLAG`（生スライス） / `init` および `entry` コールバックのスキップフラグ |
| `0x1B00` | `ContainerHeader` における Huffman テーブルの最大バイトサイズ（`tree_size`） |

## 静的復元と IL2CPP メタデータ

| 定数 | 対象・用途 |
| --- | --- |
| `0x9B`、`0x9D`、`0x9E` | 必須の基本 ELF 復元モジュール（暗号設定、主コンテナー + 補助 ELF コンテナー、隠蔽シンボル） |
| `0x96`、`0x98`、`0x0C` | 任意の静的復元モジュール（補助シンボルシード、`.init_array` コンストラクター復元インタープリター、`v24.1` メタデータシード + 例外テーブル） |
| `0x403`、`0x101`、`0x401`、`0x402` | 補助 AArch64 再配置タイプ: `RELATIVE`、`ABS64`、`GLOB_DAT`（以上 `relocation1`）、および `JUMP_SLOT`（`relocation2`） |
| `0xD65F03C0`（`RET`） | `0x98` によるコンストラクター復元時に除去される `.init_array` のダミーターゲット |
| `0xFAB11BAF`、バージョン `24`（`v24.1`）・`29`・`31`・`39` | 確認された外部 IL2CPP メタデータのマジック値と対象レイアウト |
| `0xA6FAE968` | モジュール `0x0C` で確認された既定の `MethodDef` 置換シード |
| `0x2701F30`、`[0x9732CA38, 0xBAC4374F]` | XOR マスク付き埋め込みスリム v24 メタデータのサイズと、マスク解除後のバイトスワップ済みヘッダープローブ dword |
