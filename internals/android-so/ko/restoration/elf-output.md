# ELF 출력

`PT_LOAD` 세그먼트와 동적 링킹 테이블 재구축이 끝나면, ELF 마무리 단계에서 보호 전용 구조체를 제거하고 메모리에 로드되지 않는 파일 후미 영역을 다시 작성합니다.

1. **`SHT_LOUSER` 제거:** 파일 끝에 붙은 전용 섹션 헤더를 삭제하며, Stage 1 및 Stage 2 페이로드 바이트는 출력 파일에 복사하지 않습니다.
2. **`e_entry`를 `0`으로 초기화:** Android 공유 라이브러리는 `e_entry` 대신 `.init_array`를 통해 네이티브 생성자를 실행하므로 `e_entry`를 0으로 설정합니다.
3. **비할당(non-`SHF_ALLOC`) 섹션 재배치:** 유지되는 비할당 섹션(`.shstrtab` 등)을 로드 가능한 세그먼트(새로 추가된 `PF_R` `PT_LOAD` 포함) 끝부분 뒤에 모아 배치하고, `.shstrtab`을 검증한 뒤 갱신된 섹션 헤더 테이블(`Elf64_Shdr`)을 파일 끝에 기록하며 `e_shoff`와 `e_shnum`을 갱신합니다.
4. **원자적 저장 및 재파싱:** 출력 파일은 임시 파일에 먼저 기록한 뒤 원자적 교체(atomic rename)로 저장하고, 저장된 바이트를 다시 읽어 재파싱합니다.

{% hint style="info" %}
**저장 후 필수 검증과 구조 진단.** 출력 검증은 두 단계로 나뉩니다.
* **치명적 오류(복원 중단):** ELF64 리틀 엔디언 AArch64 파싱 실패, 출력 파일 길이를 초과하는 `PT_LOAD` 파일 범위, 손상된 `.shstrtab`, 남아 있는 `SHT_LOUSER` 섹션, 0이 아닌 `e_entry`, 또는 재구축된 테이블과 일치하지 않는 `.dynsym` / `.rela.dyn` / `.rela.plt` 엔트리 개수.
* **테이블 간 교차 진단(경고로 보고):** `PT_LOAD` 정렬·합동 조건(congruence)·중첩에 대한 링커 순회 검사, `DT_*` 태그와 섹션 간 일치 여부, `DT_RELACOUNT` 앞부분 정렬 순서, 심볼 해시 버킷 범위, 재배치 대상 및 심볼 인덱스 범위, `.init_array` / `.fini_array` 함수 포인터 유효성.
{% endhint %}
